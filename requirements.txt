# EdgeShield Requirements Pointer
#
# EdgeShield dependencies are split by component to keep deployments lightweight:
#
# 1. PC Client Telemetry Agent:
#    pip install -r client/requirements.txt
#
# 2. Central Ingestion Server:
#    pip install -r server/requirements.txt
#
# 3. Web Dashboard API Backend:
#    pip install -r web/backend/requirements.txt
#
# 4. Local Unit Testing & Spark Development:
#    pip install pytest>=8.0.0 pytest-mock>=3.12.0 pyspark>=3.5.0
#
# Refer to the component README files for setup and execution instructions.
