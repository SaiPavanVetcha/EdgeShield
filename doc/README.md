# EdgeShield Documentation & Presentation Workspace

This workspace contains the presentation website for the EdgeShield project.

## Presentation Directory

The complete presentation app is located in [`presentation/`](./presentation/):

```bash
cd presentation
npm run dev
```

### Interactive Workflow Assets

The presentation includes an interactive architecture workflow embedded on Slide 4. The workflow files (`index.html`, `script.js`, and `style.css`) are located in `presentation/public/workflow/`.

For full details, please refer to [`presentation/README.md`](./presentation/README.md).
